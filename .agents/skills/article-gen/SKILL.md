# 技术文章生成技能 (Article Generator)

## 一、 技能定位

从面试准备内容 → 高质量技术文章的转化流水线。

**一鱼三吃逻辑**：
```
面试题学习 → 沉淀到 01-interview-qa/
                ↓（选题：有深度 + 有项目实战的题）
           → 扩写成技术文章 → 03-articles/草稿/
                ↓
           → 发布到各平台（掘金 / 公众号 / CSDN / 小红书）
                ↓
           → 精华内容整理到 knowledge-site
```

---

## 二、 选题标准

以下类型的面试题适合写成文章：

| 类型 | 说明 | 发布平台建议 |
|------|------|-------------|
| **原理深挖** | 某个概念的完整解析（如：RAG 完整流程） | 掘金、知乎 |
| **踩坑实录** | 项目中遇到的真实问题和解法 | 掘金、CSDN |
| **对比分析** | A vs B 的深度对比（如：RAG vs Fine-tuning） | 掘金、知乎 |
| **实战教程** | 手把手带你实现某功能 | 掘金、CSDN |
| **面试复盘** | 某次面试遇到的题目解析 | 小红书、知乎 |

## 三、 文章结构标准

### 技术深度文（掘金 / 公众号主要格式）

```markdown
# [标题：要有爆点，如「面试必问」「一文搞懂」「从 0 到 1」]

> [一句话说清楚这篇文章解决什么问题，读者读完能得到什么]

## 前言

[为什么写这篇文章？这个问题为什么重要？用 1-2 个小故事或场景引入]

## 目录

[如果文章超过 2000 字，必须有目录]

## 正文各章节

[每章节必须图文并茂，涉及架构/流程的必须配合 gpt-image-gen 出图]
[每个要点后面跟代码示例或实际案例，不讲空话]

## 结合实战项目

[如果有项目相关内容，这里讲实战经验，是文章的差异化亮点]

## 总结

[不是废话总结，而是给读者留 1-3 个行动项：「你可以去试试...」]

## 参考资料

[列出参考链接]
```

### 小红书版（轻量级，图文为主）

```
[封面图 - 必须] + 标题（含emoji，30字以内）
正文：用短句 + emoji，核心要点不超过 5 条
结尾：「你有遇到过这个问题吗？」引导互动
标签：#AI开发 #大模型 #程序员 #面试 #Python
```

## 四、 文章生产流程

```
Step 1：选题确认
  → 用户指定题目，或从 01-interview-qa/ 中推荐高价值题目

Step 2：内容扩写
  → 在面试题文档基础上深度展开
  → 加入背景、原理、实战案例、代码示例
  → 添加"结合 ai-agent-platform 项目"的实战内容（差异化核心）

Step 3：信息图生成
  → 调用 gpt-image-gen 为文章生成配图
  → 封面图（hero-metaphor 模板）
  → 核心概念图（infographic-grid-lecture 或 exploded-diagram-tech）

Step 4：草稿存档
  → 保存至 03-articles/drafts/YYYY-MM-DD-[slug].md
  → 更新发布追踪表 03-articles/README.md

Step 5：平台适配（可选）
  → 根据目标平台，调整格式
  → 掘金版 / 公众号版 / 小红书版
```

## 六、 爆款标题公式

- `一文搞懂 [XXX]：从原理到项目实战`
- `面试必问！[XXX] 的完整解析（附项目代码）`
- `我用 [XXX] 解决了 [具体问题]，踩了这些坑`
- `大模型应用开发避坑指南：[XXX] 的 N 种错误姿势`
- `[概念A] vs [概念B]：面试官最爱问的那些对比题`
