# 项目关联技能 (Project Linker)

## 一、 技能定位

**ai-agent-platform** 是用户最大的差异化竞争力。面试中说"我在项目里做过这个"，比背书强 10 倍。

本技能负责：
1. 判断面试题是否与项目有关联
2. 深入项目代码，找到具体的实现位置
3. 生成可以直接开口说的"实战回答"
4. 必要时将项目中的设计决策整理为专项说明文档

## 三、 工作流程

### Step 1：题目关联判断

收到面试题后，判断以下维度是否与项目相关：

| 关联类型 | 描述 | 处理方式 |
|----------|------|----------|
| **直接相关** | 项目中有这个功能的具体实现 | 精确定位到文件/函数 |
| **间接相关** | 项目中有类似问题的解决思路 | 说明设计决策与取舍 |
| **踩坑相关** | 项目曾遇到这个坑并解决了 | 重点！这是最有价值的回答 |
| **无关** | 项目中没有涉及 | 标注"项目无关"，跳过 |

### Step 2：项目代码探索

```bash
# 搜索相关实现
rtk rg "关键词" /Users/lijiaxin/PyCharmMiscProject/ai-agent-platform --type py -l
```

探索优先级：
1. 先看 README 和核心模块结构
2. 搜索关键词定位相关文件
3. 精读相关函数/类的实现

### Step 3：生成实战回答

实战回答必须包含：

```markdown
## 🔗 结合项目的实战回答

**项目中的体现**：
[用 1-2 句话说清楚项目里哪个模块/功能涉及了这个知识点]

**具体实现**：
[结合代码说明是如何实现的，可以引用关键代码片段]

**设计决策 & 取舍**：
[为什么这样设计？有没有考虑过其他方案？]

**踩坑记录**：（如有）
[遇到了什么问题，怎么解的，学到了什么]

**面试时的开口方式**：
「在我自己做的 ai-agent-platform 项目中，[...]，当时遇到了 [具体问题]，最终通过 [具体方案] 解决了...」
```

### Step 4：专项说明文档（选做）

当某个项目特性值得单独展示时，生成专项文档存入 `02-my-project/`：

```
02-my-project/
├── README.md                    # 项目整体介绍（面试版）
├── rag-implementation.md        # RAG 实现专项
├── agent-design.md              # Agent 设计专项
└── engineering-decisions.md     # 关键工程决策汇总
```
