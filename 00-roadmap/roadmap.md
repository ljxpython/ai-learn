## 🎯 每周目标

- 第 1 周：建立题库骨架，完成 RAG + Agent 核心题目（P0 优先）
- 第 2 周：LangChain + Prompt 工程 + 工程实践

- 第 4 周：模拟面试 + 查漏补缺 + 结合项目深化

## 💡 面试战术备忘

1. **开场必备**：准备一段 3 分钟的项目自我介绍（ai-agent-platform 为核心）
2. **答题结构**：是什么 → 为什么 → 怎么做 → 项目里怎么做的
3. **遇到不会的**：「这块我了解基本原理，但在实际项目中我更多关注的是...」
4. **主动引导**：把话题引到自己熟悉的 ai-agent-platform 项目
